# Support

## Questions and bug reports

Once the repository is public, use GitHub Issues for reproducible Archie bugs and focused usage questions. Include the Archie version, operating system, installation method, expected behavior, actual behavior, and the smallest safe reproduction you can provide.

Do not attach private repository source, generated architecture artifacts, credentials, private remotes, or customer data. Replace sensitive names and paths with synthetic examples before posting.

Language-specific scanner bugs belong in that scanner's repository. Scanner protocol and compatibility proposals belong in the [`entorn-scanner-contracts`](https://github.com/Entorn-dev/entorn-scanner-contracts) repository. Hosted SaaS and cloud operations are outside this repository.

Community support is provided on a best-effort basis; no response time or service-level agreement is promised.

## Security vulnerabilities

Do not report vulnerabilities through a public issue. Follow [SECURITY.md](SECURITY.md).
